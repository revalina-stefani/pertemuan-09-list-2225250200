Tujuan

Mempelajari penggunaan list Python untuk menyimpan, membaca, mengubah, dan mengolah data numerik.

Struktur Program
latihan/01_buat_list.py: membuat dan membaca list.
latihan/02_indeks_slicing.py: mempelajari indeks dan slicing.
latihan/03_manipulasi_list.py: mengubah, menambah, menyisipkan, dan menghapus elemen.
latihan/04_agregasi_nilai.py: menghitung total, rata-rata, minimum, dan maksimum.
latihan/05_filter_kelulusan.py: menyaring nilai mahasiswa yang lulus.
latihan/06_fungsi_statistik.py: menghitung rata-rata menggunakan fungsi.
praktik/analisis_nilai_mahasiswa.py: menganalisis nilai dan menentukan kelulusan mahasiswa.
Cara Menjalankan
